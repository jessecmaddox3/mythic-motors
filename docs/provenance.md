# Source and art provenance

> **TL;DR:** The game began as a personal AI-assisted build directed by Jess Maddox. This release contains the complete reusable game, procedural models and sound, verified local dependencies, and a new fictional illustration.

The original single-file engine was preserved while separating HTML, styling and JavaScript for maintenance. No personal story, household information, original website history, analytics, or private conversation identifiers are included. General fixes are made in this public engine and can be adopted by the personal website at a reviewed release.

Three.js is the exact unmodified r128 distribution from the [official repository](https://github.com/mrdoob/three.js/tree/r128). Its local SHA256 is `9274bbcec8d96168626c732b5d31c775aa8cfb7eaa0599bec0c175908a2c1ce2`. The complete MIT notice is bundled. The older version is retained to preserve this game's existing rendering behavior.

The five WOFF2 files are unmodified Google Fonts files: Bungee v17, Bungee Shade v17 and Chakra Petch v13. Exact versioned source URLs and hashes are in `public/fonts/SOURCES.json`. Full SIL OFL notices are included beside them. No runtime font service is required.

The truck models, trees, rocks, crystals, ruins, roads, track preview diagrams and textures are generated by the game's code. Sound is synthesized locally with Web Audio. No outside model or sound pack is bundled.
