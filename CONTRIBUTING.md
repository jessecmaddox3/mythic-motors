# Make it better

> **TL;DR:** Useful bug reports and small, clear improvements are welcome. Keep the existing game playable and the downloaded version independent of outside services.

For a bug, describe your browser, the track/truck/difficulty, what you did, and what happened. A screenshot from a fresh game helps. Do not attach browser profiles, private conversation exports or unrelated personal files.

For code changes, run `npm test` and `npm run build`. Gameplay or input changes also need the offline browser checks. Describe what changed and how you checked it. Keep dependency and font notices with their files, and record the source and license for any new asset.

Good contributions include accessible controls, broader browser testing, clearer feedback and new tracks. General improvements belong in this engine so every pinned copy can use them. This is a personal project, with no promised review schedule.
